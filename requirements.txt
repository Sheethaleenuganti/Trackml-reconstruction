# TrackML Track Reconstruction — Step 3 environment
#
# Versions below are pinned to what was verified working in the development
# environment on 2026-08-20. Record the *actual* versions your machine
# resolves to by running `python scripts/check_environment.py` after install
# and copying its output into docs/environment_verified.txt.
#
# IMPORTANT: the official TrackML utility library is NOT the "trackml"
# package on PyPI. A package named "trackml" does exist on PyPI (version
# 0.1.12 at time of writing) but it is an unrelated, unmaintained project
# (an experiment-tracking client) that happens to have claimed the same
# name. Installing it will not error, but it has nothing to do with this
# project and does not provide load_event, score_event, etc.
#
# The real library must be installed directly from the organizers' GitHub
# repository:
#
#   pip install "git+https://github.com/LAL/trackml-library.git"
#
# or, for local development with editable changes:
#
#   git clone https://github.com/LAL/trackml-library.git
#   pip install -e ./trackml-library
#
# This requirements.txt intentionally does NOT list a plain "trackml==X.Y"
# pin for that reason — see docs/DATA_ACCESS.md for the full explanation.
